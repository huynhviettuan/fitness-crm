# 20 — Glossary

| Term | Meaning |
|---|---|
| Customer | Gym customer/member with one unique CRM identity |
| Customer Code | Human/business-facing unique customer ID, generated by the server |
| Contract | Purchased package/agreement owned by one customer |
| Contract Code | Human/business-facing unique contract identifier, generated by the server |
| Total Sessions | Number of sessions purchased in a contract |
| Completed Sessions | Number of the contract's bookings with status COMPLETED |
| Remaining Sessions | Total Sessions minus opening sessions used (imported contracts) minus Completed Sessions |
| Opening Balance | Sessions used and amount paid before go-live, recorded once on an imported contract (D-011) |
| Expired Contract | An ACTIVE contract whose end date is before today in the gym timezone; derived, not stored |
| Booking | Scheduled PT appointment; owns the lifecycle status; does not prove service delivery |
| Active Booking | Booking with status BOOKED, CHECKED_IN, or COMPLETED; occupies the trainer's time slot |
| Check-in | Manual confirmation that the customer arrived |
| Session | Fulfillment record of a booking, created at check-in; stores who checked in and completed, and when |
| Completed | Final booking status that consumes one contract session |
| Cancelled | Booking/session cancelled; no session consumed in V1 |
| No-show | Customer did not attend; no session consumed in V1 |
| Payment | Contract payment record |
| Confirmed Payment | Payment with status CONFIRMED; contributes to paid amount |
| Void | Marking a payment or cash transaction as cancelled, with a reason, while keeping the record |
| Debt | Contract value minus opening paid amount minus confirmed payments |
| Cash Transaction | Internal income/expense entry |
| Idempotency Key | Client-generated ID sent with a create request so a retry or double-click does not create a second record |
| Gym Timezone | Timezone used for "today", reports, and contract expiry; set by `GYM_TIMEZONE` |
| Trainer / PT | Personal trainer assigned to bookings |
| Audit Event | Immutable history of critical system actions |
| RBAC | Role-Based Access Control |
